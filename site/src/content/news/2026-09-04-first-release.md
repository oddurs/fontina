---

fontina 0.1.0 is tagged, the first release. It is the project formerly called
unifont, renamed and relicensed under GPL-3.0-or-later in the same release, with the
core library and the command line: indexing, search and facets, tags and
collections, health checks, CSS and HTML specimens, per-user activation and
installation on Linux, macOS and Windows, watched folders, shaped previews in the
terminal, and the keyboard-first browser.

Binaries for Linux (x86_64 and aarch64), macOS (Apple silicon and Intel) and
Windows are on the [release page](https://github.com/oddurs/fontina/releases/tag/v0.1.0),
each with a checksum and a build provenance attestation, plus `.deb` and `.rpm`
packages and an SPDX bill of materials. The [download page](../../download/) says
how to verify them.

Pre-1.0: command output, schemas and check identifiers may still change, and the
changelog will say when.
