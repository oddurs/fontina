ADR 0010 decided the browser shows structure and never draws type: "the resolution is
the medium". It deleted the preview pane, the waterfall sheet and the comparison sheet,
and named where looking at type happens instead — `s` writes a self-contained HTML
specimen and opens it.

That makes the specimen the whole of fontina's graphical surface. Every question a person
opens a font manager to ask, and that the terminal deliberately refuses to answer, has to
be answerable there or nowhere.

PLAN.md §11 then makes it load-bearing twice over. The graphical shell is deferred behind
an experiment: use the specimen key for a month on a real library and write down what was
reached for and not found. That note decides whether fontina ever builds a desktop app —
so every gap in the specimen is a false argument for building one. Someone who reaches for
a paper colour, does not find it, and writes it down has recorded "the specimen was not
enough" when the truth was twenty lines of CSS.

This milestone closes the gaps that would corrupt that evidence, in the order that a
person actually hits them.
