Thirty-four commands; twenty-five flags on `list` alone. That is a toolkit, and a
toolkit is the right thing for a script to hold. It is the wrong thing to hand a person
who wants to use a font.

The work is not to remove commands — every one of them is somebody's Tuesday, and the
project's own rule is that the command line is the product and nothing is locked away
from it. The work is to put a **spine** through them: a small set of verbs that carry
the ordinary path, with the rest reachable rather than in the way.

The spine is direct manipulation, which in a terminal means *select, then act*. You are
looking at a face; you activate it. You are looking at four; you compare them. The
command that would have done it is shown, so the browser teaches the command line
instead of competing with it — which is the one idea in this program that Apple never
had and should have.

Also: the words. `facets` is a database term. `covers` is a verb with no object.
`--script-min` is a query language wearing a flag's clothes. The names are what a person
has to think in, and thinking in somebody else's schema is the tax this milestone
repeals.
