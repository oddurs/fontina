# 0004 — Project license: MIT OR Apache-2.0

**Status:** accepted, 2026-09-03

## Decision
Dual MIT / Apache-2.0 for every crate and the app, the Rust ecosystem convention. Apache
provides an explicit patent grant; MIT maximises compatibility.

## Consequences
Contributions are accepted under the same terms (see CONTRIBUTING.md). Fixture fonts
keep their own licenses and are listed in `fixtures/README.md`.
